# 新增一个源，三步就行，阅读器不用动

合集版的源都是“接口 + 实现 + 登记”三件套，界面只认接口，不认具体网站。
想加一个新源，按这三步走：

## 1. 选接口，按种类实现

- 漫画：实现 `src/sources/manga.ts` 里的 `MangaSource`（搜索、详情、章节、章节图片）
- 小说：实现 `src/sources/novel.ts` 里的 `NovelSource`（热门、搜索、详情、章节正文）
- 画廊：实现 `src/sources/gallery.ts` 里的 `GallerySource`（列表、详情、预览、单页图片）

实现里只做一件事：把那个源返回的数据，翻译成接口里的统一字段。
翻译不干净的地方（比如标题有多种语言、封面要拼地址），都在实现里处理掉，不要漏到界面上。

## 2. 在注册表里登记

打开 `src/sources/index.ts`，在 `SOURCES` 里加一行：种类、id、名字、一句话说明。
书架顶上的“浏览全部源”会自动出现这个源，不用再改界面。

## 3. 跑通三条线再算接好

- 列表能出来（搜关键词、翻页加载更多都正常）
- 点进去详情能出来（标题、作者、章节或预览格子）
- 点章节或图片能进阅读器（漫画、画廊是图片翻页，小说是文字）

三条都通了，这个源才算接好；只通列表不算。

## 不接的东西（这三条是硬的）

- 需要另一个 App 内嵌私有密钥才能调的私有接口，不抄密钥、不接
- 需要登录、Cookie、镜像、绕网络限制才能看的源，不接
- 针对版权小说站的抓取插件，不内置；LNReader 那种用户自己装插件的路子，
  是以后另起一个“插件安装”功能时再议的事，不是在这里偷偷把抓取塞进去
